## Controls outside repository automation

The owner must configure these repository or platform settings after reviewing the pull request:

1. Protect `main` and release-tag patterns.
2. Require successful checks and CODEOWNER review.
3. Dismiss approvals after new commits.
4. Configure a protected GitHub `production` environment with required human reviewers where the account plan supports it.
5. Add Vercel credentials only to protected repository/environment secrets.
6. Set `VERCEL_CLI_VERSION` to a reviewed pinned version.
7. Enable preview or production workflows only through their explicit repository variables.

Until those actions are complete, the controlled production workflow remains disabled.
