# STRUCTURA Material Calculators — Stage 1 Complete

This package contains **36 working standalone material calculators** and **42 recovered 3D technical icons**.

## Run

Keep the folder structure intact and open `index.html` in a modern browser.

## Structure

- `index.html` — working calculator landing page.
- `calculators/` — 36 standalone HTML calculators.
- `assets/icons/` — 42 transparent WebP icons recovered from the approved contact sheet.
- `documentation/` — calculator and icon registers.
- `qa/` — automated browser and content test reports.

## Status

Internal Stage 1 beta. Every displayed route performs a calculator-specific quantity calculation and has no external JavaScript, CSS or network dependency. Independent quantity-surveyor/engineering review, country-default review, product-data verification, localisation review and production integration remain required before public publication.
